# LegaleEaseAI

## Project Description

LegaleEaseAI is an AI-powered application designed to help users understand legal information in a simple and accessible way.

## Features

- AI-powered legal assistance
- Simple explanation of legal information
- User-friendly interface
- Backend and frontend integration
- Testing support

## Technologies Used

- Artificial Intelligence
- Generative AI
- Python
- Frontend Technologies
- Backend Technologies

## Project Structure

- `backend/` - Backend application files
- `frontend/` - Frontend application files
- `tests/` - Testing files
- `requirements.txt` - Required Python packages

## Installation

1. Clone this repository.
2. Install the required dependencies.
3. Configure the environment variables.
4. Run the application.

## Important

Do not upload or share your API keys or passwords. Keep sensitive information inside the `.env` file.
